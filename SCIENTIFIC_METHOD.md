# GeoAnomaly Pro Scientific Method

## 1. Objective
Identify statistically unusual geospatial signatures that merit field investigation.

## 2. Non-claims
The platform does not directly detect underground objects. Satellite data alone does not justify claims of a specific buried object, depth or archaeological identity.

## 3. Evidence hierarchy
1. Data quality and provenance
2. Independent source agreement
3. Spatial persistence
4. Temporal persistence
5. Geological context
6. Structural context
7. Statistical anomaly strength
8. Multi-scale consensus
9. Field validation

## 4. Target score
The current target score is an evidence/anomaly ranking score. It is not a probability.

## 5. Reproducibility
Every analysis should preserve AOI, dates, datasets, filters, scale, algorithms, parameters, model version and outputs.

## 6. Field validation
A target becomes a scientifically useful training/validation example only after its field outcome is recorded with sufficient provenance.

## 7. Cross-platform verification
A result should be considered stronger when independently reproducible in another GIS/remote-sensing workflow using the same inputs and parameters.
